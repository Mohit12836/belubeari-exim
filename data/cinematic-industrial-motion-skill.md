# Cinematic Industrial Motion Design System (Belubeari Exim Project Skill)

This skill provides the complete **Color System**, **Motion Architecture**, **Section Rhythm**, and **Component Standards** for building world-class Industrial Technology Showrooms, B2B Engineering Brands, Precision Hardware Catalogs, and Motion-Driven Commercial Websites.

---

## 🎨 1. Core Color Palette & Rhythm Architecture

The website MUST NEVER be all-black or flat-white. Dark sections are restricted to **maximum 25–30%** of total page height. The layout visibly shifts between vibrant electric tones, clean white surfaces, rich atmospheric blue gradients, and deep graphite.

| Token Name | Hex Code | Semantic Role |
